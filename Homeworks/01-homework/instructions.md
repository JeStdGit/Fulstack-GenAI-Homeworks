# Objective

Initial familiarity with creating an HTML file, using basic tags (text and lists), and understanding the difference between running a local file and using a development server (Live Server).

## Requirements

Create and upload a valid HTML file. Ensure the file contains at least the following tags:

* A main heading (`<h1>` tag).
* One paragraph of text (`<p>` tag).
* Include two different types of lists on the page (e.g., an ordered list `<ol>` and an unordered list `<ul>`).

*(Optional/Recommended)*: Run your file using the Live Server extension and notice the difference in the browser's address bar compared to opening the file normally.
