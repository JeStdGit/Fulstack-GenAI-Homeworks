4. What is the difference between inheritance and polymorphism?
answer: in inheritance each class inherits the parent method as is without changing it becouse it has an universal method that acts the same for any of it's childs, in polymorphism the parent method is there in order to set a standart for any of it's childs so they couldn't implement without having these methods this forces the same pattern for every class that inherits from this 'parent' class
