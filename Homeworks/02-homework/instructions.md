# Web Development Tasks

## Task 1: Working with Forms and Server-Side Simulation
**Objective:** Practical experience in building HTML forms and integrating a third-party service for data collection without writing backend code.

**Requirements:**
* Create an HTML page containing a form (e.g., contact us, registration, or a survey).
* The form must include at least 4 different types of input fields (e.g., text, email, checkbox, radio, date, etc.).
* You must include a dropdown menu using the `<select>` and `<option>` tags.
* Connect the form to the Formspree service to simulate server-side data reception. Ensure that upon clicking the Submit button, the data is successfully sent and displayed in the Formspree dashboard.

## Task 2: CSS Precedence and Specificity
**Objective:** Understanding the browser's cascading mechanism and how styling precedence (specificity) is calculated between different selector types and implementation methods.

**Requirements:**
* **Location Precedence:** Create an HTML element and apply conflicting styles (e.g., different background colors) simultaneously in three ways:
    1. External stylesheet
    2. Internal `<style>` tag within the `<head>`
    3. Inline styling directly on the tag
    * *Demonstrate on the page (e.g., via text or code comments) which style "won" and why.*
* **Selector Specificity:** Create another HTML element and give it both a Class and an ID. Attempt to style it using the tag name, the Class, and the ID with conflicting definitions. Demonstrate the practical power hierarchy of the selectors.
